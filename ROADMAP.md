# AR-CAT-UCF Roadmap

## About

This roadmap details all of the planned/upcoming features and the dedicated version which the features are expected to be implemented in. 

This does not include any bug fixes, and focuses on the base changes, so from V3.0.0 to V3.1.0. 

## Roadmap

### V3.0.0 (Current Version)

- [ ] Initial re-factor
- [x] New zone handling improvements
- [ ] Code re-organization
- [x] New dataclasses
- [ ] Alert re-integration
- [ ] Alert mapping
- [ ] Forecast information
- [ ] Base preparedness messages

### V3.1.0

- [ ] Extra bot commands
- [ ] Weather radar implementation on a select few alerts
- [ ] Upgraded and/or checking of current alert tracking and handling for new, changed, cancelled, or expired alerts
- [ ] Extra preparedness messages

### V3.2.0 

- [ ] Expanded bot commands
- [ ] Weather watch supplements from KML feeds and from the SPC website
- [ ] Configuration commands and storage of any configuration changes

### V3.3.0 

- [ ] Implementation of alert storage and databasing features with SQLite
- [ ] Re-implementation of alert track ids

### V3.4.0 

- [ ] Edited messages + deleted messages based upon track-ids
- [ ] Bot commands to allow for users to browse alert records and history
- [ ] Initial testing of alert statistics

### V3.5.0

- [ ] Mesoscale discussion implementation
- [ ] Precipitation discussion implementation from the WPC

### V3.6.0

- [ ] Alert summary/diff implementation
- [ ] Extra safety messages, with the ability to create and send custom safety messages
- [ ] Possible context-based alert upgrades, with a ping and re-sending of messages for upgraded alerts

### V3.7.0 

- [ ] Viewing of weather radar
- [ ] Command to view active mesoscale discussions and current severe weather outloook
- [ ] Mesoscale discussion summary implementation

### Other Planned Features

These features are planned but have no definite version by which they will be added.

- [ ] CAT voice alerts in a discord voice channel
- [ ] CAT voice over repeater
- [ ] CAT over MQTT
- [ ] Multiple server support
